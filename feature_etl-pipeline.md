# feature/etl-pipeline

## Objetivo
Preparar, limpar e enriquecer os dados de jogos e avaliações, garantindo que todos os campos necessários estejam prontos para uso pelo backend e serviço de recomendação.

## Tarefas
- Unificar datasets (Steam, Amazon, etc)
- Limpar e normalizar campos (títulos, gêneros, plataformas, etc)
- Extrair e salvar comentários, links, tags/gêneros
- Gerar tabelas finais para jogos e avaliações
- Validar integridade dos dados
- Documentar pipeline e comandos de execução

## Critérios de aceite
- Dados prontos e acessíveis para backend e recommender-service
- Scripts reprodutíveis e documentados
